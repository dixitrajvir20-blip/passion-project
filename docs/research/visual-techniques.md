# Web-platform & design research for an Astro 7 educational site (verified 17 Sep 2026)

Legend: C/F/S = Chrome/Firefox/Safari. NA = Baseline "Newly available", WA = "Widely available", LTD = "Limited availability" (not Baseline). WFE = https://web-platform-dx.github.io/web-features-explorer/features/ (append the id). Current stables: C151 (28 Jul 2026), F153 (21 Jul 2026), S27 (14 Sep 2026, https://developer.apple.com/documentation/safari-release-notes/safari-27-release-notes.md).

## Part 1 — Techniques

**1. View transitions.** Cross-document: both pages opt in with `@view-transition{navigation:auto}`, same-origin only; `pageswap`/`pagereveal` events; `types` descriptor + `:active-view-transition-type()`; `view-transition-class` styles many groups at once (https://developer.chrome.com/docs/web-platform/view-transitions/cross-document). Support: C126 (Jun 2024), S18.2 (Dec 2024), F none (bug 1860854) → LTD "blocked 21 months by Firefox" (WFE cross-document-view-transitions). Same-document `startViewTransition` is NA since F144 (Oct 2025) (WFE view-transitions); `view-transition-class` NA (C125/S18.2/F144) (WFE view-transition-class); types are Baseline 2026 per MDN, but F147 supports SPA types only, not cross-document (https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/147). Astro `<ClientRouter/>` = same-document SPA router with `fallback="animate|swap|none"`, `transition:name/animate/persist`, `astro:page-load` etc., auto-disables animation under `prefers-reduced-motion`; docs say native cross-doc transitions make it "increasingly unnecessary" (https://docs.astro.build/en/guides/view-transitions/); it is incompatible with Astro's CSP feature (https://docs.astro.build/en/reference/configuration-reference/). Fallback: none needed — navigation works, just unanimated. Caveats: duplicate `view-transition-name`s skip the transition; width/height group animations cause per-frame layout; use `<link rel=expect blocking=render>` sparingly. Recommendation for a static, CSP'd, ≤50 KB site: native cross-doc VT, no ClientRouter.
```css
@view-transition{navigation:auto; types: article}
.hero-img{view-transition-name: hero}
@media (prefers-reduced-motion){::view-transition-group(*),::view-transition-old(*),::view-transition-new(*){animation:none !important}}
```

**2. Scroll-driven animations.** `animation-timeline: scroll()|view()`, `animation-range: entry/exit/cover/contain`; composited props run off main thread (https://developer.chrome.com/docs/css-ui/scroll-driven-animations). C115 (Jul 2023), S26 (15 Sep 2025), F none (bug 1676779; flag `layout.css.scroll-driven-animations.enabled`) → LTD (WFE scroll-driven-animations). Fallback: wrap in `@supports (animation-timeline: view())`; Firefox gets the static end state. Gate all of it in `prefers-reduced-motion: no-preference`.

**3. Anchor positioning.** caniuse: C125–150 partial, 151+ full; S26.0–26.6 partial, S27 full; F147+ partial; 85.9% global (https://caniuse.com/css-anchor-positioning). F147 (13 Jan 2026) enabled by default. WFE still shows LTD/not Baseline. Fallback: `@supports (anchor-name:--x)`; otherwise render the popover in-flow under its trigger.

**4. Popover, hint, @starting-style, allow-discrete.** Popover API NA since Jan 2025 (C116, F125, S17; iOS 18.3) (WFE popover). `popover="hint"` shipped C133, F153 (Jul 2026), S none. Hint falls back to `manual` in unsupporting browsers. `@starting-style` NA Aug 2024 (C117/F129/S17.5); `transition-behavior: allow-discrete` NA Aug 2024 (C117/F129/S17.4). Fallback: popover toggles without animation. Popover gives top-layer, Esc and light-dismiss for free.

**5. Invokers.** `command`/`commandfor` NA since 12 Dec 2025 (C135, F144, S26.2) (WFE invoker-commands). `interestfor`: C142 only (Oct 2025); F bug 1984699; S none; spec still a WHATWG PR. Fallback: feature-detect `'command' in HTMLButtonElement.prototype` and attach a click handler. Don't put essential content behind hover-only interest.

**6. Customizable `<select>`.** C135 (Apr 2025); S27 (14 Sep 2026: `appearance: base-select` + `<selectedcontent>`); F none → LTD. Fallback is graceful; MDN warns some frameworks break SSR hydration — keep it in `.astro`, not a Preact island.

**7. interpolate-size / calc-size / ::details-content.** `interpolate-size`/`calc-size()`: C129 only; F/S bugs open → LTD. `::details-content` NA 16 Sep 2025 (C131/S18.4/F143). Fallback: instant open.

**8. Color.** `light-dark()` NA May 2024 (C123/F120/S17.5); `color-scheme` WA Aug 2024; oklch/oklab WA Nov 2025; `color-mix()` WA Nov 2025; relative color NA Sep 2024 (C125/F128/S18). Fallback: declare hex tokens first, override inside `@supports (color: oklch(0 0 0))`. Check WCAG contrast on the gamut-mapped result.

**9. Container/style/scroll-state queries.** Size queries WA Aug 2025; style queries NA 19 May 2026 (C111/S18/F151); `scroll-state()` C133 only, F bug 1931980, S none. Rules must target descendants of the `container-type: scroll-state` element (https://developer.chrome.com/blog/css-scroll-state-queries). Fallback: IntersectionObserver sentinel (§14).

**10. Selectors/typography/properties.** `:has()` WA Jun 2026; `text-wrap:balance` NA May 2024; `text-wrap:pretty` C117 + S26, F none; `field-sizing:content` NA Jun 2026 (C123/S26.2/F152); `@scope` NA Mar 2026 (C143/F146/S26.4); `@property` NA Jul 2024 (C85/S16.4/F128); CSS `if()` C137 only. All degrade silently. Animated counters: keep the real number in text for AT; animate a visually-only layer.

**11. Speculation Rules.** C109 only; F "neutral, concerns: complexity"; S bug 295193 → LTD. Eagerness `immediate|eager|moderate|conservative`; limits 10 prerenders / 2 FIFO; check `document.prerendering`; analytics may double-count (https://developer.chrome.com/docs/web-platform/prerender-pages). Astro `prefetch` uses `<link rel=prefetch>` else `fetch()`; `experimental.clientPrerender` swaps in a speculation-rules `<script>` (https://docs.astro.build/en/guides/prefetch/). Note a CSP inline `script-src` hash will be needed.

**12. Web Share.** `navigator.share`: S12.1+ (macOS), iOS 12.2+, C89–127 partial → 128+ full, Edge 95+, F desktop none through 159, F Android 155+ (https://caniuse.com/web-share). Files: web.dev lists C128+, Edge 93+, S12.1+, F behind flag. Needs HTTPS + transient activation. Fallback: Clipboard copy + PNG download.

**13. Frosted bars.** `backdrop-filter` NA Sep 2024 (C76/F103/S18 unprefixed) — keep `-webkit-backdrop-filter` for older Safari. Ancestors with `opacity`/`filter`/`will-change` become backdrop roots and limit the blur. `prefers-reduced-transparency`: C119 only; Safari cites privacy; F none. Apple's sub-nav: 80% opacity + backdrop-blur, 52 px (https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md). Perf: blur one thin bar only.

**14. Sticky sub-nav.** apple.com is vanilla JS: IntersectionObserver + `position:sticky` + transforms (https://profiletree.com/apple-website-programming-language/). Use `scroll-state(stuck)` with an IO sentinel fallback (https://developer.chrome.com/blog/sticky-headers); highlight the active section via IO on headings → `aria-current`; add `scroll-padding-top` so anchors aren't hidden under the bar; `<nav aria-label="On this page">`. ~1 KB JS.

**15. Reveal-on-enter.** CSS `view()` timelines: 0 JS, compositor-driven, no Firefox (§2). IO: universal, ~0.5 KB. Do CSS inside `@supports`, IO only if Firefox parity matters; never start `opacity:0` outside those gates so no-JS/unsupported users see content; gate with `prefers-reduced-motion`. The Pudding warns scrollytelling is time-intensive and needs mobile/desktop care; steppers are simpler (https://pudding.cool/process/how-to-make-dope-shit-part-3/).

## Part 2

**A. Astro 6/7.** 6.0 (10 Mar 2026): dev server on Vite Environment API, Fonts API, Live Content Collections stable, automatic CSP; Node 22+, Vite 7, Zod 4, Shiki 4 (https://astro.build/blog/astro-6/). Removed: legacy collections, `<ViewTransitions/>`, `Astro.glob()`; `redirectToDefaultLocale` now defaults false (https://docs.astro.build/en/guides/upgrade-to/v6/). 7.0 (22 Jun 2026): Rust compiler default (15–61% faster; strict closing tags), Vite 8/Rolldown, Sätteri Markdown pipeline, queued rendering + route caching stable, `src/fetch.ts`, `compressHTML:'jsx'`; removed `@astrojs/db` and `astro:transitions` internals (https://astro.build/blog/astro-7/, https://docs.astro.build/en/guides/upgrade-to/v7/). 7.1 (16 Jul): `script-src-elem/attr` CSP directives, `deferRender` (https://astro.build/blog/astro-710/). 7.2 (6 Aug): experimental incremental static builds via `cacheKey` (https://astro.build/blog/astro-720/). 7.3 (3 Sep): preview `--ignore-lock` (https://astro.build/blog/astro-730/). Fonts: `fonts[]` with local/google/fontsource/bunny/adobe providers, `<Font cssVariable preload/>`, `experimental_getFontFileURL()` for OG images (https://docs.astro.build/en/guides/fonts/). CSP: `security.csp` emits `<meta http-equiv>` with SHA-256 hashes; build/preview only; `<ClientRouter/>` and Shiki listed as incompatible. Server islands need an adapter — not applicable to a static site.

**B. OG images.** satori: JSX→SVG via Yoga flexbox; no grid/`calc()`/z-index; fonts as TTF/OTF/WOFF buffers (no WOFF2) (https://github.com/vercel/satori) + `@resvg/resvg-js` → PNG in a `getStaticPaths` endpoint. astro-og-canvas: canvaskit-wasm, `OGImageRoute` (https://github.com/delucis/astro-og-canvas). Build-time cost scales per page; Playwright screenshots are slow (https://jilles.me/og-images-astro-build-vs-runtime/).

**C. Pagefind.** v1.5.2 (12 Apr 2026); 1.5.0 added web-component UI, Web-Worker search, ~45% smaller chunks (https://github.com/pagefind/pagefind/releases). Payload <300 kB for 10k pages, ~100 kB typical (https://pagefind.app/). `bundlePath` auto-detected — set it when hosting under a subpath (https://pagefind.app/docs/ui/). With Astro `base`, `astro-pagefind` v2.0.1 (3 Jul 2026) supports custom base (https://github.com/shishkin/astro-pagefind). Load on search focus to keep article pages at 0 KB.

**D. Charts** (bundlephobia min/gz): uplot 1.6.32 49.6/21.3 KB, canvas, no animations, README silent on a11y; chart.js 4.5.1 196/67 KB, canvas — add `role="img"`/`aria-label` or fallback content; @observablehq/plot 0.6.17 375/125 KB SVG; frappe-charts 1.6.2 66/19 KB SVG. Under 50 KB with Preact, only hand-built SVG (or uPlot) fits; SVG in Preact gives real DOM (`<title>`/`<desc>`, focusable points, a visually-hidden data table). OWID's Grapher renders SVG with React/MobX (https://github.com/owid/owid-grapher).

**E. Sites & patterns.** Ciechanowski — many small inline slider/drag demos, one idea each (https://ciechanow.ski/). Nicky Case — play-first simulations (https://ncase.me/); Explorable Explanations hub (https://explorabl.es/). Josh Comeau — bespoke MDX widgets, restrained micro-interactions (https://www.joshwcomeau.com/blog/how-i-built-my-blog-v2/). The Pudding — stacked single charts, scrollytelling, stepper; one takeaway per chart. Distill — reactive diagrams; 50+ hours per article (https://distill.pub/2021/distill-hiatus/). Stripe Press — content-first minimalism (https://press.stripe.com/). Our World in Data — one consistent SVG chart system. Bloomberg "What's Really Warming the World?" — sticky graphic + stepper; NYT Snow Fall — pinned full-bleed media; Apple — pinned product with scroll-driven state. Brilliant — "every session is visual and interactive". Khan Academy and NYT Upshot: not verified this session.

**F. Apple pages.** Community-measured tokens: SF Pro Display headlines 56/40/34/28 px with −0.28…−0.374 px tracking; body SF Pro Text 17 px/1.47; weights 300/400/600/700; canvas #fff/#f5f5f7, text #1d1d1f, dark ≈#272729, action blue #0066cc; 80 px section padding; text max ≈980 px, grids ≈1440 px; pill buttons 9999 px, cards 18 px; "no decorative gradients, no shadows on chrome, only the one signature drop-shadow"; elevation by alternating surface colour and backdrop-blur (VoltAgent DESIGN.md). Another measurement: Display 40/44, Heading 32/36, Body 17/25, secondary #6e6e73, control radius 12, "white is the main spacing device", hairline dividers instead of cards (https://design.withfudge.com/share/apple.com-design). Tech: no framework, IO + sticky + transforms, image sequences swapped by scroll % (profiletree, Aug 2026); the canvas flip-book pattern used 148 frames/55.8 MB — a poor fit for a performance budget (https://css-tricks.com/lets-make-one-of-those-fancy-scrolling-animations-used-on-apple-product-pages/). Content: chunking with generous whitespace; map specs to relatable contexts. SF Pro's licence limits it to Apple platforms — choose another typeface.

**G. Avoiding "AI slop".** Impeccable's 61 rules: purple→blue gradients, halo glows on dark, decorative glassmorphism, Inter/Geist defaults, flat hierarchy, icon-in-rounded-square feature cards, nested cards, identical grids, em-dash overuse, "supercharge" copy (https://impeccable.style/slop/). 925 Studios (Jun 2026): Inter; indigo→purple; three rounded cards; weightless headlines + thin-line icons; "generic is worse than ugly" (https://www.925studios.co/blog/ai-slop-design-tells). DEV (Sep 2026): fixes: a binding DESIGN.md, one aesthetic direction, semantic colour, a banned list (https://dev.to/james_anderson_h/the-purple-gradient-problem-why-ai-ui-all-looks-alike-and-how-to-fix-it-3j65). Superdesign (Jul 2026): centred hero + gradient blob, stock section order → left-aligned hero, varied section sizes, specific hex palette, one accent (https://superdesign.dev/blog/fix-generic-ai-landing-page). Practical translation: a typeface with character, one accent, zero gradients/glows, hairlines over nested cards, varied section rhythm, specific numeric copy.
