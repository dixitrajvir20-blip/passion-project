# LaunchPad

A free, global learning hub that teaches business ideas, entrepreneurship and money
skills to people aged 15–21 — with a focus on those who don't have access to a
financial adviser or family guidance.

Built as a college passion project.

## What's here

| Path | Purpose |
| --- | --- |
| `index.html` | Home page — mission, topics, latest articles |
| `articles/` | Article library |
| `css/style.css` | All site styles |
| `js/main.js` | Mobile navigation |
| `assets/` | Images and other static files |

## Running it locally

No build step and no dependencies — it's plain HTML, CSS and JavaScript.

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
